内容工作台便携版（Windows 10/11 64 位）
========================================

一、直接打开
1. 必须右键压缩包并选择“全部解压”。不能在压缩包预览窗口内直接双击启动文件。
2. 双击“启动内容中台.cmd”。如果电脑无法正确显示中文文件名，也可以双击完全相同的“START.cmd”。
3. 浏览器会自动打开 http://127.0.0.1:4173/
4. 不使用时可双击“停止内容中台.cmd”或“STOP.cmd”。
5. 启动后会保留一个“内容工作台服务”窗口；请保持该窗口打开。若启动失败，窗口会显示具体原因，不会再一闪而过。

二、压缩包已包含
- 构建完成的内容工作台页面。
- 独立桥接服务。
- Windows 版 Node 运行时，无需另装 Node.js。
- ffmpeg，用于从已下载视频中提取音频。
- 当前采集结果的 JSONL 元数据（不包含约 3GB 的原始媒体文件）。

三、连接 MediaCrawler
- 内容库浏览和已打包元数据可直接使用。
- 新建采集任务、停止采集等功能需要目标电脑上的 MediaCrawler API 在 8080 端口运行。
- 如 MediaCrawler 数据目录不在压缩包内，请打开 config.env，把 MEDIACRAWLER_DATA_DIR 改成目标电脑上的 data 文件夹绝对路径，然后重启中台。
- 本便携版没有修改 MediaCrawler 源码、配置或采集逻辑。

四、AI 功能配置
- 为避免密钥跟随压缩包外泄，API 密钥未预填。
- 第一次启动后会自动生成 config.env；用记事本打开并填写豆包、DeepSeek、CogView 的密钥。
- 豆包“录音文件识别 2.0”还需要一个公网可访问的 HTTPS 地址，填写 DOUBAO_ASR_PUBLIC_BASE_URL 后重启中台。

五、素材说明
- 新下载的封面、视频和音频会写入 downloaded-assets 文件夹。
- 如需迁移当前电脑已下载的全部媒体，可单独复制原项目的 downloaded-assets 文件夹；当前文件约 1.1GB，因此未放进便携压缩包。

六、端口
- 页面：4173
- 桥接服务：4174
- MediaCrawler API：8080
- 如果端口被其它程序占用，可在 config.env 中调整前两个端口；页面端口改变后请手动打开对应地址。
